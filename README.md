# swipeClean — Privacy Policy

Public hosting for the swipeClean iOS app's privacy policy, published via
GitHub Pages at <https://jk-kai.github.io/swipeclean-privacy/>.

This URL is referenced by:

- App Store Connect (app privacy policy URL)
- Google AdMob (privacy policy URL required to publish a GDPR consent message)

The page itself is a single self-contained `index.html` with no dependencies.
Edit it and push to update; GitHub Pages redeploys automatically. Keep the
"Last updated" date at the top current whenever the content changes.
